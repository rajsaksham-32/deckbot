# DeckBot 🎴

A Discord bot that draws magical cards using `!deck`.

## Setup

```bash
git clone https://github.com/rajsaksham-32/deckbot.git
cd deckbot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Create a .env file:
DISCORD_TOKEN=your_token_here


python -m src.main


Save and exit.
